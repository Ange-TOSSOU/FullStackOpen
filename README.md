# Full Stack Open

Full Stack Open is an introduction to modern web development with JavaScript. It's a course delivered by the Helsinki University which covered the topics below :

- Single-page applications
- React
- NodeJS
- Express
- RESTful
- GraphQL
- CI/CD
- TypeScript
- React Native
- Next.js
- Relational databases

Find more about this course on their [website][full_stack_open_material].

The course contains a bunch of exercises. Some of them can be really challenging.
I created this repository to save all my solutions for those problems. Feel free to try its out, compare its to yours and give me your feedback if needed.


[full_stack_open_material]: https://fullstackopen.com/
